敬語法
尊敬語・謙譲語・丁寧語の3種類と、重要敬語動詞をしっかりマスターしましょう
はじめに敬語の3種類
古典語の敬語は現代語と同じく3種類です。ただし、誰が誰に対して敬意を表しているかを正確に把握することが大切です。

尊敬語（赤）：話題の中の人物の動作を高めて、その人物に敬意を表します。「〜なさる・〜いらっしゃる」
謙譲語（青）：話題の人物の動作を低めて、動作の受け手に敬意を表します。「〜申し上げる・参上する」
丁寧語（緑）：読み手（聞き手）に直接敬意を表します。「〜ございます・〜です」
敬意の方向を押さえましょう：
尊敬語 → 動作の主語（する人）への敬意
謙譲語 → 動作の対象（される人）への敬意
丁寧語 → 読み手・聞き手への敬意（書き手から）

解説補助動詞としての敬語
動詞の下について意味を付け加える補助動詞（〜なさる・〜申し上げる）も重要です。
主な補助動詞は次のとおりです。
補助動詞意味（尊敬）意味（謙譲）意味（丁寧）
給ふ（四段）〜なさる
給ふ（下二段）〜申し上げる・〜ます
おはす・おはします〜いらっしゃる
侍り・さぶらふ〜ございます・〜ます
奉る・聞こゆ〜申し上げる
最重要「給ふ（たまふ）」の識別
「給ふ」は古典語で最も重要な敬語です。四段活用か下二段活用かで意味が変わります。

四段活用（は・ひ・ふ・ふ・へ・へ）
・本動詞「与ふ」の尊敬語 → 「お与えになる」
・補助動詞 → 「〜なさる」（尊敬）

下二段活用（へ・へ・ふ・ふる・ふれ・へよ）
・補助動詞のみ → 「〜申し上げる・〜ます」（謙譲）

見分け方：連体形が「給ふ」ならば四段（尊敬）、「給ふる」ならば下二段（謙譲）
活用未然連用終止連体已然命令意味
四段はひふふへへ尊敬
下二段へへ○ふるふれへよ謙譲
⚠ 識別のポイント：
連体形：「給ふ（=四段・尊敬）」vs「給ふる（=下二段・謙譲）」← この違いが最頻出！
下に「けり（連用形接続）」がある場合：「給ひ」＋けり → 連用形「ひ」＝四段（尊敬）or「へ」＝下二段（謙譲）？
→ 文脈（誰が誰の動作を語っているか）で判断します。
演習②「参る・詣づ」と「罷る・罷づ」
参る（まゐる）・詣づ（まうづ）→ 謙譲語。高貴な場所へ「参上する」の意味が基本。
ただし「参る」には複数の意味があります。
①「行く・来」の謙譲語 → 参上する
②「食ふ・飲む」の尊敬語 → 召し上がる（直上に飲食語がある場合）
③「与ふ」の謙譲語 → 差し上げる
④補助動詞 → 〜申し上げる

罷る（まかる）・罷づ（まかづ）→ 謙譲語。高貴な場所から「退出する・おいとまする」の意味。
「まかり〜」（接頭語）→「〜させていただく・〜します」
演習②：口語訳
①「殿の召しあれば、参りたり」 → 参上した
②「少将も御酒少しばかり参る」 → 召しあがる
③「憶良らは今はまからむ」（万葉集）→ おいとまいたしましょう
④「心地も苦しければ、ものもつゆばかりまゐらず」→ 少しも召し上がらない
⑤「まかり通る」の意味 → 通らせていただく
演習③「聞こゆ」「奉る」「のたまふ」
聞こゆ（きこゆ）→ 謙譲語。「言ふ」の謙譲語「申し上げる」が基本。
ただし自発の意味「聞こえる・うわさされる・わかる」もあります（直接的な会話文でない場合）。

奉る（たてまつる）→ 謙譲語。「与ふ・着せる・乗せる・飲ませる」などの謙譲。補助動詞なら「〜申し上げる」。

のたまふ（宣ふ）→ 尊敬語。「言ふ」の尊敬語「おっしゃる」。
演習③：口語訳
①「世の人、『光の君』ときこゆ」→ 申し上げる
②「これ、昔名高く聞こえたるところなり」→ 評判が高く噂されていた（自発）
③「御返りなど聞こえたり」→ 申し上げた（謙譲）
④「帝、のたまはく、……」→ おっしゃるには（尊敬）
演習④入試問題にチャレンジ
問 ① 〈センター試験〉
「思ひたまへらむ」の文法的説明として正しいものを選べ。
①おもひ(名詞)・たまへ(四段動詞)・らむ(推量助動詞)
②おもひ(動詞)・たまへ(四段補助動詞)・ら(完了助動詞)・む(推量助動詞)
③おもひ(動詞)・たまへ(四段補助動詞)・らむ(推量助動詞)
④おもひ(動詞)・たまへ(下二段補助動詞)・ら(完了助動詞)・む(推量助動詞)
答え：②
「たまへ」の活用を確認します。四段｜は・ひ・ふ・ふ・へ・へ｜の已然形「へ」です。四段の已然形にはサ変未然・四段已然に接続する完了の助動詞「り」が付きます（「り」の接続：さみしい）。よって「ら」は完了「り」の未然形、「む」は推量の助動詞です。「おもひたまへ」は動詞「思ふ」＋四段補助動詞「給ふ」の已然形です。
問 ② 〈明治大〉
「思ひ（Ａ）給へて食ひ候ひつるなり。…笑はせ（Ｂ）給ひける。」
ＡとＢの「給ふ」それぞれの活用形名と文法的意味（尊敬・謙譲）を答えよ。
Ａの活用形：連用形　Ａの意味：謙譲
Ｂの活用形：連用形　Ｂの意味：尊敬
Ａ「給へ」は下二段の連用形「へ」→謙譲の補助動詞。Ｂ「給ひ」は四段の連用形「ひ」で、下に「ける（連用形接続）」があるので連用形→尊敬の補助動詞。
